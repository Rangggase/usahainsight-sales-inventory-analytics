# UsahaInsight — Naskah Demo Portofolio (3–5 menit)

> Rekam layar dengan database **demo sintetis**. Jangan membuka SQL Console yang berisi hash/session token atau data nyata.

| Durasi | Tampilan | Narasi yang disarankan |
|---|---|---|
| 0:00–0:30 | Halaman login dan dashboard | “UsahaInsight membantu toko kecil mengubah transaksi harian menjadi informasi omzet dan stok. Ini adalah aplikasi web FastAPI lokal.” |
| 0:30–1:10 | Katalog produk | “Pemilik dapat mengelola produk, menentukan stok minimum, dan mengarsip produk tanpa menghapus riwayat penjualan.” |
| 1:10–2:00 | Form penjualan dan invoice | “Satu transaksi bisa memuat beberapa produk. Sistem memeriksa stok dan mencatat invoice, detail item, serta pergerakan stok secara konsisten.” |
| 2:00–2:35 | Persediaan dan dashboard | “Perubahan stok tersinkron dengan laporan dan dapat ditelusuri kembali.” |
| 2:35–3:25 | Analitik Persediaan | “Laju penjualan dihitung per 7, 30 atau 90 hari; produk baru tidak langsung dilabeli lambat terjual.” |
| 3:25–4:15 | Rekomendasi restock | “Waktu tunggu pemasok, safety stock, dan periode tinjau menghasilkan rekomendasi kuantitas yang dapat dijelaskan, bukan prediksi AI.” |
| 4:15–4:45 | Audit Trail dan dokumentasi | “Audit Trail, pengujian otomatis, ERD, backup/restore, dan dokumentasi mendukung keterlacakan keputusan.” |

**Penutup:** “Fokusnya adalah ketepatan alur bisnis dan transparansi perhitungan. Ini prototipe portofolio untuk penggunaan lokal single-admin dan belum di-deploy sebagai layanan publik.”

Bila ingin merekam lebih singkat, pilih dashboard → transaksi → analitik → restock → kesimpulan. Jangan tampilkan data sensitif.
